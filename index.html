jpshadereditorInclude

Una composición de nodos,
como fondo de tu página.

Este fondo NO es una imagen ni un video: es el render WebGL en vivo de la composición nodeeditor-0857, servida por el nodeeditor. Si la editás y la volvés a guardar, esta página se actualiza sola.

Cómo se usa

Un solo <script> en el header. Nada más.

<script src="…/jpshadereditor/include.js"
        data-comp="nodeeditor-0857"
        data-pass="ndlf4r28qv"></script>

Panel secreto

Apretá S en cualquier parte de esta página: se abre el panel donde pegás el link del nodeeditor y le ponés ese fondo a la página. También te da el <script> listo para copiar.

El link tiene esta pinta: nodeeditor.html?output=1&comp=…&pass=…

Se actualiza solo

El sistema vive en el backend: el servidor resuelve la composición a un plan de render (GLSL final, cables, uniforms y orden) y esta página sólo lo aplica. Cada 20 s se vuelve a pedir ⇒ lo que guardás en el nodeeditor aparece acá.

API desde consola

JPShaderInclude.set('nodeeditor-0857', 'ndlf4r28qv')
JPShaderInclude.state()
JPShaderInclude.reload()
JPShaderInclude.clear()
JPShaderInclude.openPanel()
